# نماذج لغوية بعمق مشترك

دراسة لبنية نموذج لغوي على مستوى البايت: هل يمكن إعادة استخدام كتلة محوّل واحدة ثلاث مرات بدل ثلاث كتل مستقلة مع خفض المعاملات؟

استخدمت النماذج 1,115,394 بايتًا من نصوص شكسبير، ومفردات ثابتة من 256 رمز بايت، وسياقًا من 64 بايتًا. جرى اختيار نقاط الحفظ باستخدام مجموعة تحقق متصلة زمنيًا، ثم التقييم على 111,488 هدفًا محفوظًا.

خفضت مشاركة العمق المعاملات من 121,024 إلى 54,080، بنسبة 55.3%، لكنها زادت البتات لكل بايت في الاختبار بمقدار 0.1458. الأقل أفضل لهذا المقياس؛ لذلك اختير المحوّل القياسي.

إعادة استخدام الكتلة تقلل عدد الأوزان، لكن تمريرات الانتباه والطبقات ما زالت تُنفذ ثلاث مرات. لا يعني خفض المعاملات تسارعًا متناسبًا. هذه نماذج بحثية صغيرة، وليست مساعدات عامة أو نماذج محادثة مضبوطة بالتعليمات.
